# Personal Portfolio Website

Welcome to my personal portfolio! This website showcases my skills, projects and education as a developer.

## 🌐 Live Demo

[View My Portfolio](https://emon9999-9.github.io/portfolio/)

## ✨ Features

- About me section with a short bio, quick stats and education
- Skills and technologies, grouped by area
- Services I offer
- Project showcase with a details pop-up for each project
- Live GitHub stats, top languages and recent repositories
- Contact form
- Dark and light mode
- Quick-jump menu (press `⌘K` or `Ctrl+K`)
- Responsive design for phones, tablets and desktops

## 🛠️ Technologies Used

- HTML5
- CSS3
- Tailwind CSS
- JavaScript

## 📂 Project Structure

```text
portfolio/
├── index.html
├── css/
│   └── custom.css
├── js/
│   ├── data.js
│   └── main.js
└── README.md
```

## ✏️ Updating the Content

All of the site's content lives in `js/data.js`: bio, skills, services, projects, education, social links and GitHub username. Edit that file to update the site. You don't need to touch the HTML.

## 🚀 Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

An internet connection is needed, because Tailwind CSS, the fonts and the GitHub stats load online.
